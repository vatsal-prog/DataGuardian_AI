The path a row takes

  1. Data sourcesCSV, JSON, APIs, PostgreSQL
  2. Ingestion agentUnderstand the source and schema
  3. Data profilerTypes, statistics, distributions
  4. Quality agentDetect issues
  5. Root-cause agentWhy did it happen?
  6. Repair agentGenerate safe fixes
  7. Validation agentDid the fix work?
PassStore in the database, then ask questions or read the dashboard.
FailRoll back the publish and wait for a person to review.

Human review
